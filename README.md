# Linux Server Monitor

A Python-based Linux system monitoring tool designed to monitor basic server health and system resources.

## Features

- CPU usage monitoring
- RAM usage monitoring
- Disk space monitoring
- System uptime tracking
- Server health reporting

## Technologies

- Python 3
- Linux (Ubuntu)
- Git
- GitHub
